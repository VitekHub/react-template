# React Template

A React 19 + TypeScript starter with TanStack Router, TanStack Query, Zustand, Tailwind CSS v4, and i18n built in.

## Stack

| Layer | Choice |
| --- | --- |
| UI | React 19, Tailwind CSS v4, lucide-react, Sonner |
| Routing | TanStack Router (file-based, auto code splitting) |
| Data | TanStack Query |
| State | Zustand |
| Validation | Zod |
| i18n | i18next + react-i18next (lazy-loaded namespaces) |
| Build | Vite, TypeScript (strict) |
| Quality | ESLint, Prettier (with Tailwind class sorting), Vitest + Testing Library |

## Requirements

- Node.js 20+
- npm (a `package-lock.json` is committed)

## Getting started

```bash
npm install
npm run dev
```

The dev server starts on http://localhost:5173.

## Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the Vite dev server |
| `npm run build` | Type-check (`tsc -b`) and build for production |
| `npm run preview` | Serve the production build locally |
| `npm test` | Run Vitest in watch mode |
| `npm run test:run` | Run all tests once |
| `npm run lint` | Run ESLint |
| `npm run format` | Format sources with Prettier |
| `npm run format:check` | Verify formatting without writing |
| `npm run typecheck` | `tsc --noEmit` for app and node configs |
| `npm run validate` | Lint + format + tests + typecheck (writes formatted files) |

Run a single test file:

```bash
npm run test:run src/lib/utils.test.ts
```

Don't put `--` before the path — npm would hand it to Vitest as a name filter and run every matching test instead.

## Project structure

```
src/
├── features/          # Feature modules; pages live in <feature>/ui/
├── i18n/
│   ├── config.ts      # i18next setup (lazy JSON backend)
│   └── locales/       # <language>/<namespace>.json
├── lib/               # Shared utilities (query client, cn helper)
├── routes/            # TanStack Router file-based routes
├── stores/            # Zustand stores
├── test/              # Vitest setup and render helper
├── providers.tsx      # QueryClient + Router providers
├── router.tsx         # Router instance
└── main.tsx           # Entry point
```

The `@/*` alias maps to `src/*` in both Vite and TypeScript.

## Routing

Routes are files in `src/routes/`. Create `src/routes/about.tsx` with:

```tsx
import { createFileRoute } from '@tanstack/react-router'
import { AboutPage } from '@/features/about/ui/AboutPage'

export const Route = createFileRoute('/about')({
  component: AboutPage,
})
```

`src/routeTree.gen.ts` is generated by `@tanstack/router-plugin` on dev/build — never edit it. Route files stay thin and delegate rendering to a feature component.

`src/routes/__root.tsx` renders the `<Outlet />` and the Sonner `<Toaster />`.

## Data fetching

A single `QueryClient` (`src/lib/query-client.ts`) is created with:

- `staleTime: 5 minutes`
- `retry: 1`
- `refetchOnWindowFocus: false`

Wrap queries in TanStack Query hooks inside the relevant feature folder.

## Internationalization

Translations are loaded lazily from `src/i18n/locales/<language>/<namespace>.json`.

- Languages: English (`en`, fallback) and Czech (`cs`)
- Default namespace: `common`
- Language is detected from localStorage key `react-template-language`, then the browser

To add a language, add the locale folder and register it in `supportedLngs` in `src/i18n/config.ts`. To add a namespace, create the JSON file in each locale folder and add its name to `ns`.

## Code style

Prettier is configured with no semicolons, single quotes, trailing commas, a 100-character print width, and Tailwind class sorting. ESLint extends the recommended TS/React Hooks configs with Prettier compatibility; `src/routes/**` may export `createFileRoute` results freely, and `src/test/**` helper re-exports are exempt from the React Refresh rule.

## Testing

Tests use Vitest with jsdom and are colocated with sources as `*.test.ts(x)`.

Import `render`, `screen`, and `userEvent` from `@/test/utils` rather than `@testing-library/react`. The helper wraps components in a fresh `QueryClient` (retry disabled) and an eagerly-loaded English i18next instance with Suspense off.
